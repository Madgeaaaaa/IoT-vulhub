# 固件说明

固件本体**不入库**（体积大、版权归厂商）。

## 需要放哪个文件

| 文件名 | 版本 | 适用硬件 |
|---|---|---|
| `DIR815A1_FW103b01.bin` | 1.03 | Rev A1（Ralink RT3662，本环境默认目标） |
| `DIR815A1_FW103SP_b25.bin` | 1.03SP | Rev A1（不同区域版本，结构类似） |

> Rev E / S / R 用的是 Realtek RT8197F/G，固件完全不同，**不要混用**。

## 获取方式

D-Link 已停止对老型号的官方下载支持，常见来源：

1. D-Link 区域支持站（如 `support.dlink.ru`、`ftp.dlink.by`）的 `/pub/Router/DIR-815/Firmware/RevA/`
2. 互联网档案馆的 D-Link 支持页快照
3. 二手设备自带的配置光盘 / 升级包

下载后**校验并记录**（写进下面的表格，方便复现对账）：

| 文件 | 大小 | sha256 |
|---|---|---|
| DIR815A1_FW103b01.bin | 3.5 MB | `待填` |

```bash
sha256sum firmware/DIR815A1_FW103b01.bin
```

## 合法性

仅用于本地仿真研究。不要二次分发固件，不要把仿真环境暴露到公网。
